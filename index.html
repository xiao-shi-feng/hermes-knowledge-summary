它能干什么？

在 AI 对话结束时，自动追加一段 📚知识点总结，包含：

🧠
提炼核心
1-3句抓住对话最有价值的结论
🗣️
类比说人话
复杂概念配生活化比喻，零门槛理解
🎯
行动导向
不只告诉你"聊了什么"，更告诉你"下次怎么做"
⚡
开箱即用
无需配置，任何模型都适用，中文环境优先

效果对比

❌ 没有这个 skill
用户：免费 AI 模型有什么区别？

AI：免费模型有次数限制，付费更快……

——聊完就忘，等于没聊
✅ 有这个 skill
用户：免费 AI 模型有什么区别？

AI：免费模型有次数限制，付费更快……

📚知识点总结
- 类比：免费模型 = 实习生前台
- 免费适合简单任务，关键任务用付费
- 下次选模型前：先想清任务是"日常杂活"还是"重要工程"

——带走一条真正有用的判断标准

快速安装

Hermes Agent

方式一：直接安装

hermes skills install https://raw.githubusercontent.com/xiao-shi-feng/hermes-knowledge-summary/main/skills/knowledge-summary/SKILL.md

方式二：添加源，随时更新

hermes skills tap add xiao-shi-feng/hermes-knowledge-summary
hermes skills install knowledge-summary

其他 Agent（Claude Code / Codex / Cursor 等）

复制 skills/knowledge-summary/SKILL.md 到对应技能目录即可使用。
